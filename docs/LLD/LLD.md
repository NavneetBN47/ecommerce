# COMPREHENSIVE BACKEND ENGINEERING SPECIFICATION PACKAGE\n## Shopping Cart System - Spring Boot MVC Implementation\n\n---\n\n## EXECUTIVE SUMMARY\n\n### Project Overview\nThis document provides a complete backend engineering specification for implementing a shopping cart system using Java Spring Boot MVC architecture. The system supports user management, product catalog search, and shopping cart operations with strict business rules enforced at both service and database levels.\n\n### Key Highlights\n- **Architecture**: Spring Boot MVC (Stateless)\n- **Database**: Relational Database with Database-First Validation\n- **API Style**: RESTful APIs\n- **Core Domains**: User Management, Product Catalog, Shopping Cart Management\n- **Total APIs**: 11 REST endpoints\n- **Domain Entities**: 4 core entities (User, Product, Cart, CartItem)\n\n### Critical Business Rules\n1. Cart lifecycle is tied to user session (auto-delete on logout)\n2. Lazy cart creation (created only when first item is added)\n3. Empty carts are automatically deleted\n4. Database-level constraints enforce all business rules\n5. Stateless authentication (no session persistence)\n\n### Out of Scope\n- Checkout and payment processing\n- Inventory locking mechanisms\n- Admin management interfaces\n- Password change functionality\n\n---\n\n## Technical Artifacts\n\n### 1. Entity-Relationship Diagram (ERD)\n\n```mermaid\nerDiagram\n    USERS ||--o{ CARTS : owns\n    CARTS ||--o{ CART_ITEMS : contains\n    PRODUCTS ||--o{ CART_ITEMS : references\n    \n    USERS {\n        bigint id PK\n        varchar email UK\n        varchar name\n        varchar password\n        timestamp created_at\n        timestamp updated_at\n    }\n    \n    PRODUCTS {\n        bigint id PK\n        varchar name\n        text description\n        decimal price\n        int stock_quantity\n        bigint version \"optimistic locking\"\n        timestamp created_at\n        timestamp updated_at\n    }\n    \n    CARTS {\n        bigint id PK\n        bigint user_id FK\n        varchar status\n        timestamp created_at\n        timestamp updated_at\n    }\n    \n    CART_ITEMS {\n        bigint id PK\n        bigint cart_id FK\n        bigint product_id FK\n        int quantity\n        decimal price_at_addition\n        timestamp created_at\n        timestamp updated_at\n    }\n```\n\n### 2. Add to Cart Sequence Diagram\n\n```mermaid\nsequenceDiagram\n    participant Client\n    participant CartController\n    participant CartService\n    participant ProductRepository\n    participant CartRepository\n    participant Database\n\n    Client->>CartController: POST /api/carts/{userId}/items\n    CartController->>CartService: addItemToCart(userId, productId, quantity)\n    \n    CartService->>ProductRepository: findById(productId)\n    ProductRepository->>Database: SELECT * FROM products WHERE id = ?\n    Database-->>ProductRepository: Product data with version\n    ProductRepository-->>CartService: Product entity\n    \n    CartService->>CartService: Validate stock availability\n    \n    CartService->>CartRepository: findByUserIdAndStatus(userId, \"ACTIVE\")\n    CartRepository->>Database: SELECT * FROM carts WHERE user_id = ? AND status = ?\n    Database-->>CartRepository: Cart data or null\n    CartRepository-->>CartService: Optional<Cart>\n    \n    alt Cart does not exist (Lazy Creation)\n        CartService->>CartRepository: save(new Cart)\n        CartRepository->>Database: INSERT INTO carts\n        Database-->>CartRepository: New cart created\n        CartRepository-->>CartService: Cart entity\n    end\n    \n    CartService->>CartService: Check if item exists in cart\n    \n    alt Item exists\n        CartService->>CartService: Update quantity\n    else Item does not exist\n        CartService->>CartService: Create new CartItem\n    end\n    \n    CartService->>ProductRepository: save(product) - decrement stock\n    ProductRepository->>Database: UPDATE products SET stock = ?, version = version + 1 WHERE id = ? AND version = ?\n    \n    alt Optimistic Locking Failure\n        Database-->>ProductRepository: 0 rows updated\n        ProductRepository-->>CartService: OptimisticLockException\n        CartService-->>CartController: throw ConcurrentModificationException\n        CartController-->>Client: 409 Conflict - Product was modified\n    else Success\n        Database-->>ProductRepository: 1 row updated\n        ProductRepository-->>CartService: Updated product\n        \n        CartService->>CartRepository: save(cart with items)\n        CartRepository->>Database: INSERT/UPDATE cart_items\n        Database-->>CartRepository: Success\n        CartRepository-->>CartService: Updated cart\n        \n        CartService-->>CartController: CartResponse\n        CartController-->>Client: 200 OK - Cart updated\n    end\n```\n\n### 3. Database Model (SQL DDL)\n\n```sql\n-- ============================================\n-- PostgreSQL DDL for Shopping Cart System\n-- ============================================\n\n-- Drop tables if they exist (for clean setup)\nDROP TABLE IF EXISTS cart_items CASCADE;\nDROP TABLE IF EXISTS carts CASCADE;\nDROP TABLE IF EXISTS products CASCADE;\nDROP TABLE IF EXISTS users CASCADE;\n\n-- ============================================\n-- USERS Table\n-- ============================================\nCREATE TABLE users (\n    id BIGSERIAL PRIMARY KEY,\n    email VARCHAR(255) NOT NULL UNIQUE,\n    name VARCHAR(255) NOT NULL,\n    password VARCHAR(255) NOT NULL,\n    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,\n    updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,\n    CONSTRAINT chk_email_format CHECK (email ~* '^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\\.[A-Za-z]{2,}$')\n);\n\n-- ============================================\n-- PRODUCTS Table\n-- ============================================\nCREATE TABLE products (\n    id BIGSERIAL PRIMARY KEY,\n    name VARCHAR(255) NOT NULL,\n    description TEXT,\n    price DECIMAL(10, 2) NOT NULL,\n    stock_quantity INTEGER NOT NULL DEFAULT 0,\n    version BIGINT NOT NULL DEFAULT 0,\n    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,\n    updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,\n    CONSTRAINT chk_price_positive CHECK (price >= 0),\n    CONSTRAINT chk_stock_non_negative CHECK (stock_quantity >= 0)\n);\n\n-- ============================================\n-- CARTS Table\n-- ============================================\nCREATE TABLE carts (\n    id BIGSERIAL PRIMARY KEY,\n    user_id BIGINT NOT NULL,\n    status VARCHAR(50) NOT NULL DEFAULT 'ACTIVE',\n    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,\n    updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,\n    CONSTRAINT fk_cart_user FOREIGN KEY (user_id) \n        REFERENCES users(id) ON DELETE CASCADE,\n    CONSTRAINT chk_cart_status CHECK (status IN ('ACTIVE', 'CHECKED_OUT', 'ABANDONED'))\n);\n\n-- ============================================\n-- CART_ITEMS Table\n-- ============================================\nCREATE TABLE cart_items (\n    id BIGSERIAL PRIMARY KEY,\n    cart_id BIGINT NOT NULL,\n    product_id BIGINT NOT NULL,\n    quantity INTEGER NOT NULL,\n    price_at_addition DECIMAL(10, 2) NOT NULL,\n    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,\n    updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,\n    CONSTRAINT fk_cart_item_cart FOREIGN KEY (cart_id) \n        REFERENCES carts(id) ON DELETE CASCADE,\n    CONSTRAINT fk_cart_item_product FOREIGN KEY (product_id) \n        REFERENCES products(id) ON DELETE CASCADE,\n    CONSTRAINT chk_quantity_positive CHECK (quantity > 0),\n    CONSTRAINT chk_price_at_addition_positive CHECK (price_at_addition >= 0),\n    CONSTRAINT uk_cart_product UNIQUE (cart_id, product_id)\n);\n\n-- ============================================\n-- Indexes for Performance Optimization\n-- ============================================\n\n-- Index on users email for login queries\nCREATE INDEX idx_users_email ON users(email);\n\n-- Index on products name for search queries\nCREATE INDEX idx_products_name ON products(name);\n\n-- Index on carts user_id and status for active cart lookup\nCREATE INDEX idx_carts_user_status ON carts(user_id, status);\n\n-- Index on cart_items cart_id for cart retrieval\nCREATE INDEX idx_cart_items_cart_id ON cart_items(cart_id);\n\n-- Index on cart_items product_id for product reference queries\nCREATE INDEX idx_cart_items_product_id ON cart_items(product_id);\n\n-- Composite index for finding specific item in cart\nCREATE INDEX idx_cart_items_cart_product ON cart_items(cart_id, product_id);\n\n-- ============================================\n-- Comments for Documentation\n-- ============================================\n\nCOMMENT ON TABLE users IS 'Stores user account information';\nCOMMENT ON TABLE products IS 'Stores product catalog with optimistic locking support';\nCOMMENT ON TABLE carts IS 'Stores shopping cart instances for users';\nCOMMENT ON TABLE cart_items IS 'Stores individual items within shopping carts';\n\nCOMMENT ON COLUMN products.version IS 'Version number for optimistic locking to handle concurrent updates';\nCOMMENT ON COLUMN cart_items.price_at_addition IS 'Captures product price at the time of addition to cart';\n```
